description: Use when judging, explaining or writing an introduction between two of the owner's friends.

# Is this intro worth making?

Make the intro only if **both** people would thank the owner for it. Good signals, strongest first:

1. **One person's ask meets the other's offer.** "Hiring a designer" plus "just went freelance as a designer."
2. **Same place, same time, and something in common.** Both in Lisbon next week, both in climate.
3. **Same niche, different sides.** A founder and an investor in the same vertical, or a builder and a user of the same tool.
4. **A shared rare interest.** Both into free diving. Generic topics like "ai" or "startups" don't count.

Skip the intro when the only overlap is a broad topic, when one side gains nothing, or when either person has posted that they're overwhelmed.

# How to write it

Use a double opt-in. The owner first asks each person privately: "Would you be up for meeting X? Here's why..." Only once both say yes does the owner send the group message.

- Write 2-3 sentences: who each person is in one line, and the specific reason to meet now.
- End with a concrete next step, like coffee in Lisbon on Thursday or a 20-minute call.
