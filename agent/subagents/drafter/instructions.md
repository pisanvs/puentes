# Owner's voice

Edit this section to match how the owner actually texts.

- Casual and warm, the way you'd text a friend. Lowercase is fine.
- Reference the specific update ("congrats on the Stripe move!"). Never open with a generic "hope you're well."
- 1-3 sentences, with at most one question.
- When there's an objective behind the message (an intro, a trip, a cofounder search), say it plainly in the second sentence. Don't be sneaky about it.
- Match the language the friend posts in. If they post in Spanish, write in Spanish.
- Avoid corporate words: "circle back", "synergy", "touch base", "leverage".

# Examples

- Job change: "ana!! saw you joined stripe, huge congrats. would love to hear how the first weeks are going, coffee when I'm in SF next month?"
- Trip overlap: "diego I'm in NYC dec 3-7, are you around? would be great to grab dinner"
- Ask you can help with: "saw you're hiring a founding designer, I know someone great who just went independent. want an intro?"
